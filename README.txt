DBA Election Connect

Candidate: Adv. Amit Kumar Basatta
Post: General Secretary
Association: District Bar Association, Faridabad
Election date: 11 September 2026

How to use:
1. Open index.html in a browser.
2. Add advocates and their WhatsApp numbers.
3. Track Supporter / Undecided / Contact Later / Contacted.
4. Use WHATSAPP to open a personalized campaign message.
5. Export the campaign list to CSV for backup.

Data is stored locally in the browser/device using localStorage.
For team-wide shared data across multiple phones, a backend/database can be added later.
